I'm a software developer based in Edinburgh. I build open-source tooling for
evaluating AI systems, with a focus on the security of the code they write.

## Projects

- [inspect-baxbench](https://github.com/Jeffrin-J/inspect-baxbench): BaxBench
  (Vero et al., ICML 2025) for the [Inspect](https://inspect.aisi.org.uk/)
  evaluation framework. It reproduces the paper's results, and is submitted to
  the Inspect Evals register.
